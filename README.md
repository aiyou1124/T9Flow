# 轻拨 QingDial

原生 Android 中文 T9 拨号应用。当前版本 **2.0.3**，支持 Android 10 及以上，使用 Java 17 开发。

## 功能

- 置顶、排序、首次引导及关于弹窗统一使用主题面板、线条图标和按钮样式。
- 长按联系人或在联系人详情中置顶；多个置顶支持上移、下移、移至首位和取消置顶。排序保存在本机，输入搜索时仅优先显示匹配的置顶联系人，拨号按钮使用相同顺序。
- 读取本机通讯录，按姓名从左到右匹配拼音首字母，支持保持顺序的跳字匹配。例如“张三”对应 `97`，“媳妇儿”对应 `933`。
- 用橙色加粗标出输入数字对应的姓名字符，未匹配的字符不高亮。
- 首位输入 `1` 时按号码前缀筛选，兼容中国大陆手机号的 `+86` / `0086` 前缀；其他数字以姓名 T9 匹配为主，4 位以上也支持号码片段检索。
- 底部按钮优先直接拨打第一条匹配结果；无结果时拨打输入的号码。通过系统 Telecom 发起呼叫，系统电话负责通话界面。联系人右侧箭头打开该号码的独立详情页。
- 使用系统默认电话应用完成拨号、SIM 卡选择和接听；轻拨不申请成为默认电话应用。
- 显示最近 500 条系统通话记录，以绿色、蓝色、红色区分呼入、呼出、未接，并统计次数和时长。
- 联系人详情统计该号码的系统通话历史，展示最近 200 条。
- 通话记录仅用于本机只读统计，设置中可打开“通话记录统计”或“最近通话”。
- 可独立开关短促按键音和系统触感反馈。
- 缓存通讯录索引及通话记录，重开时先显示本机缓存；检测到变化、授权变化或缓存超过 5 分钟时后台刷新。
- 返回桌面时重置拨号首页及输入状态，恢复前执行兜底，并避免延迟导航结果恢复旧页面。

## 下载

在 [Releases](https://github.com/aiyou1124/T9Flow/releases/latest) 下载 APK。当前发布包为调试签名版本，与本次 ADB 安装版本使用相同签名，可覆盖更新。

## 首次使用

安装 APK 后点击“开始使用”，按系统弹窗授予通讯录权限。首次拨打时授予电话权限；首次查看通话统计时可选授予通话记录读取权限。接打电话交给系统默认电话应用。

在九宫格输入数字即可筛选联系人。长按 `0` 输入 `+`，长按删除键清空。设置页位于右上角，通讯录和最近通话入口也在设置页。

## 构建

需要 JDK 17、Android SDK Platform 36 和相应 Build Tools。Android Studio 打开仓库目录并配置本机 SDK；命令行构建时可在未提交的 `local.properties` 中设置 `sdk.dir`。

```sh
./gradlew assembleDebug lintDebug
```

Windows 使用：

```powershell
.\gradlew.bat assembleDebug lintDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。首次构建需要联网下载 Gradle 和构建插件。调试包使用本机调试证书；正式分发前需自行配置长期签名。

## 验证

- 构建和 Android Lint 通过。
- `tests/PinOrderTest.java` 包含 19 项置顶排序、过滤、首条拨号和排序恢复检查；真机验证了置顶、换序、重启保留、搜索过滤及主题弹窗。
- `tests/SearchIndexTest.java` 包含 52 项搜索、高亮和缓存序列化检查，可配合 ICU4J 75.1 在桌面 JVM 上运行。手机使用系统 Android ICU，不同系统的罕见字转写可能存在差异。
- `app/src/androidTest` 提供快速桌面切换回归。真机在输入、设置、联系人详情三个场景，以 0/40/120ms 间隔尝试切回现有任务，在任何新的首页启动 Intent 到达前验证清理状态，共 9 项通过。
- 厂商桌面动画可能忽略立即前置任务请求；测试先检查后台状态，再恢复窗口继续下一项，不把重启首页造成的清理算作通过。自动化测试不发起实际电话。

## 隐私与限制

应用没有联网权限。通讯录和通话记录仅在本机处理，缓存保存在应用私有目录；仓库不包含通讯录、通话截图、运行缓存、签名文件或开发机器 SDK 路径。

多音字采用系统 ICU 转写，并修正常见多音姓氏，不能覆盖所有个性化姓名读音。接听和通话功能由系统默认电话应用提供，实际电话连接由 Android Telecom 和运营商服务处理。

包名：`com.qingdial.app`。直接拨号使用 [Android TelecomManager.placeCall](https://developer.android.com/reference/android/telecom/TelecomManager#placeCall(android.net.Uri,%20android.os.Bundle))。
