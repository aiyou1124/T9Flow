# 轻拨 · QingDial

一款专注于中文姓名 T9 搜索的原生 Android 拨号助手。用九宫格快速找到联系人，点击即可直接拨打；接听和通话界面由手机的系统电话应用提供。

## 下载与安装

1. 打开 **[Releases 发布页](https://github.com/aiyou1124/T9Flow/releases)**。

当前 APK 使用调试证书签名，与本轮开发过程中通过 ADB 安装的 2.0.3 版本签名一致，可以覆盖更新。其他来源或不同签名的安装包不能保证直接覆盖；卸载会清除本应用保存的设置、缓存和置顶顺序。

## 主要功能

### 中文 T9 搜索

- 按中文姓名的拼音首字母进行九宫格匹配，支持保持从左到右顺序的模糊匹配。
- 支持中文、拼音首字母及全拼输入；九宫格用于快速输入数字。
- 命中的汉字以橙色加粗显示，便于看出数字与姓名的对应关系。
- 不显示未匹配的联系人，避免无关结果干扰。
- 首位输入 `1` 时按电话号码前缀匹配，兼容大陆手机号的 `+86`、`0086` 前缀；其他数字主要匹配姓名 T9，输入达到 4 位后也支持号码片段匹配。

| 联系人 | 输入示例 | 匹配方式 |
| --- | --- | --- |
| 张三 | `97` 或 `zs` | 拼音首字母 `z`、`s` |
| 媳妇儿 | `933` 或 `xfe` | 拼音首字母 `x`、`f`、`e` |
| 张小三 | `97` 或 `zs` | 按顺序跳过“小”，匹配“张”“三” |
| 号码以 138 开头的联系人 | `138` | 首位为 `1`，按号码前缀筛选 |

模糊匹配仍然要求字符顺序一致，不支持将姓名中的字任意倒序组合。

### 联系人置顶与排序

- 长按联系人，或打开联系人详情，选择“置顶联系人”。
- 多个置顶联系人支持“上移一位”“下移一位”和“移至首位”。
- 置顶联系人显示顺序标记，可随时取消置顶。
- 排序保存在本机，重新启动应用后保留，不修改系统通讯录。
- 搜索时先过滤，再按置顶顺序排列；未命中的置顶联系人不会出现。

置顶按“姓名 + 号码”保存，同一联系人的不同号码可分别管理。

### 直接拨号与系统通话

- 点击联系人条目，直接拨打该号码。
- 输入内容后点击底部拨号按钮，优先拨打当前匹配结果的第一条；没有匹配结果时，拨打输入的号码。
- 联系人右侧箭头打开独立详情页，查看该号码的通话统计和历史记录。
- 通过 Android 系统电话服务发起呼叫，SIM 卡选择遵循系统设置；接听、挂断和通话界面由系统默认电话应用处理。
- 无需将轻拨设置为默认电话应用。

### 通话记录与统计

- “最近通话”读取最近 500 条系统记录，统计其中的呼入、呼出次数和总时长。
- 呼入、呼出和未接分别以绿色、蓝色和红色区分，已接通记录显示时长。
- 联系人详情按号码汇总可读取的通话历史，并展示最近 200 条。
- 通话记录仅用于读取和统计，不修改或删除系统记录。

### 使用体验

- 紧凑九宫格，输入时展开号码和删除区域，为联系人结果保留空间。
- 可分别开关按键音与触感反馈；按键音采用标准 DTMF。
- 置顶、排序、首次引导及关于弹窗使用统一主题。
- 优先显示本机缓存，再按数据变化、权限变化或缓存时间在后台刷新。
- 返回桌面时清理输入并重置到拨号首页。

## 使用说明

1. 首次打开后，按引导允许读取通讯录。
2. 在九宫格输入姓名首字母对应的数字，查看匹配结果与汉字高亮。
3. 点击联系人或底部拨号按钮。首次拨打时，允许系统弹出的“电话”权限请求；授权后会继续拨打刚才选中的号码。
4. 长按联系人可置顶或调整顺序，点击右侧箭头可查看详情。

常用操作：

| 操作 | 入口 |
| --- | --- |
| 清空输入 | 长按删除键 |
| 输入 `+` | 长按数字 `0` |
| 查看通讯录 | 右上角设置 → 通讯录 |
| 查看通话统计 | 右上角设置 → 通话记录统计 / 最近通话 |
| 开关按键音、触感 | 右上角设置 → 使用体验 |
| 管理应用权限 | 右上角设置 → 应用权限 |

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| 读取通讯录（`READ_CONTACTS`） | 建立本机联系人搜索索引 |
| 拨打电话（`CALL_PHONE`） | 点击后直接发起呼叫 |
| 读取通话记录（`READ_CALL_LOG`） | 展示记录及统计次数、时长 |
| 振动（`VIBRATE`） | 提供按键触感反馈 |

权限由 Android 系统弹窗授权，可在系统设置中撤销。未授予通话记录权限时，仍可使用已授权的通讯录搜索功能。

应用未声明联网权限，不上传通讯录、通话记录或置顶数据。搜索索引、记录缓存与排序保存在应用私有目录中；清除应用数据或卸载会删除这些本机数据。

## 源码构建

### 环境要求

- JDK 17。
- Android SDK Platform 36 及对应 Build Tools。
- Gradle Wrapper 8.14.1（仓库已提供）。

使用 Android Studio 打开项目，配置本机 Android SDK。命令行构建可在未提交的 `local.properties` 中配置 `sdk.dir`。首次构建需要联网下载 Gradle 和构建依赖。

**Windows：**

```powershell
.\gradlew.bat assembleDebug lintDebug
```

**macOS / Linux：**

```sh
sh ./gradlew assembleDebug lintDebug
```

生成的 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

本地构建使用本机调试证书，不一定能覆盖安装 Releases 中的 APK。正式分发应配置并妥善保存长期签名证书；请勿将私钥或签名密码提交到仓库。

### 项目结构

```text
app/src/main/
├── java/com/qingdial/app/   # 搜索、拨号、置顶、统计及界面
├── res/                    # 主题与图标资源
└── AndroidManifest.xml     # 应用入口与权限
app/src/androidTest/        # Android 生命周期回归验证
tests/                      # 桌面 JVM 搜索与排序检查
gradle/wrapper/             # Gradle Wrapper
```

## 验证与已知限制

- 构建及 Android Lint 已通过。
- `SearchIndexTest.java`：52 项搜索、高亮及索引序列化检查，使用 ICU4J 75.1。
- `PinOrderTest.java`：19 项置顶顺序、过滤、首条拨号选择及顺序恢复检查。
- 真机已验证置顶、换序、重启保留、搜索过滤和主题弹窗；已有快速桌面切换的生命周期回归验证。
- 自动化验证不拨出真实测试电话，实际呼叫连接仍需结合设备、系统电话及运营商服务确认。

中文转拼音使用系统 ICU，并对部分常见多音姓氏作了修正，无法覆盖所有姓名读音。厂商系统的权限管理、SIM 卡选择及后台行为可能存在差异；通话统计范围以系统实际允许读取的记录为准。
